Privacy

A short privacy notice

This is a personal page. It has no forms, no advertising trackers and no database.

The everyday scenes

Choosing a scene happens entirely in your browser. Nothing you choose is stored, sent or logged, and the site uses no cookies or browser storage.

Hosting

The site is hosted on GitHub Pages. GitHub may log visitors’ IP addresses for security purposes under its own privacy statement. Fonts and photographs are served from this site, so no service other than GitHub sees your visit.

Search engines

Every page asks search engines not to index it. That is a courtesy signal, not access control: the page is public, and anyone with the link can read or copy it.
